# solidity-contracts

Solidity 学习合约，从 Remix IDE 工作区导出（工作区1 / ch01）。

## 文件

| 文件 | 内容 |
|---|---|
| `ch01/01常量.sol` | `constant`（编译期常量）与 `immutable`（部署期常量） |
| `ch01/02变量.sol` | 状态变量声明、构造函数赋值、函数声明、`view`/`pure` |
| `ch01/03地址类型.sol` | `address` 类型、`msg.sender`、`balance`、`payable`、转账 |
| `ch01/04转账.sol` | `payable` 与 ETH 转账（`require` 校验合约余额） |

## 编译环境

- Solidity：`>=0.8.0 <0.9.0`
